# Task Manager

A simple command-line Task Manager built using Python.

## Features

- Add a task
- List all tasks
- Mark a task as completed
- Delete a task
- Exit the application

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open `src/main.py`.
4. Run the program using the Run button or terminal:

```bash
python src/main.py
```

## Project Structure

```text
task-manager/

```

## Storage

Tasks are stored in memory while the program is running. They are not saved permanently.
